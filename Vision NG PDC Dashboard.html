Target Date to UAT here is the PDC's date: the first Monday on or after the window's 2 Week Start, plus 14 days. It can differ from the Target Date on the project dashboard, which is 2 Week Start + 14 days. Hover a target to see both dates. To UAT is measured against the project dashboard's Target Date. UAT Start and Signed Off come from the UAT Defect Log. In UAT Returned, Open UAT Def counts defects in the UAT Defect Log not yet Resolved or No Action (Returned to UAT still counts); the green ▲ is UAT defects reported since UAT Start and the red ▼ those since closed.
